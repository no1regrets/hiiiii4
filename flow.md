## 🚀 Нажатие /start

- Пользователь получает сообщение с приветственным текстом (**...**) и 4 inline-кнопками:
  - 📦 Каталог
  - 💰 Пополнить баланс
  - 🤝 Пригласить друга
  - 🛠 Поддержка

---

## 📦 Сценарий кнопки «Каталог»

- Пользователь получает сообщение со списком первых 10 товаров каталога:
  - до 3 товаров могут быть закреплены администратором и отображаются вверху списка
- Каждая позиция представлена отдельной кнопкой (карточкой товара)

### 🔽 Навигация по каталогу

Под списком товаров отображается ряд кнопок:

```
[ < ]   [ 1 ]   [ > ]
```

- **[ < ]** — переход на предыдущую страницу  
- **[ 1 ]** — текущая страница  
- **[ > ]** — переход на следующую страницу  

- Все три кнопки находятся в одном ряду  
- Ниже отображается кнопка **«Назад»**, которая возвращает пользователя в состояние `/start`

---

## 🧾 Сценарий карточки товара

- После нажатия на товар пользователь получает сообщение с подробной информацией:
  - Название товара
  - Количество единиц в наличии
  - Цена за единицу
  - Подробное описание

- Под сообщением отображаются кнопки:
  - **Купить**
  - **Назад**

---

## 🔙 Сценарий кнопки «Назад» внутри товара

- При нажатии пользователь возвращается в каталог (на первую страницу)
- Поведение идентично нажатию кнопки «Каталог» из главного меню

---

## 🛒 Сценарий кнопки «Купить»

- После нажатия пользователь получает сообщение:
  - «Введите количество единиц товара (положительное число, не превышающее доступное количество)»

- После ввода количества:
  - бот рассчитывает итоговую стоимость заказа
  - отправляет пользователю расчет
  - сравнивает сумму заказа с балансом пользователя

### Если средств достаточно:
- Отображается кнопка **«Оплатить»**

### Если средств недостаточно:
- Пользователь получает сообщение с:
  - суммой заказа
  - текущим балансом
  - суммой, которой не хватает
- Под сообщением отображаются кнопки:
  - **Пополнить баланс**
  - **Назад** (возврат в карточку товара)

### После оплаты:
- Списывается баланс
- Пользователь получает `.txt` файл со ссылками/данными приобретённого товара

---

## 💰 Сценарий кнопки «Пополнить баланс»

- После нажатия пользователь получает запрос на ввод суммы пополнения (в рублях)

- После ввода суммы бот предлагает способы оплаты:
  - Карта (РФ)
  - Crypto
  - Telegram Stars

- После успешной оплаты:
  - баланс обновляется
  - пользователь получает сообщение с суммой пополнения и текущим балансом

---

## 🤝 Сценарий кнопки «Пригласить друга»

- Пользователь получает свою реферальную ссылку (с возможностью копирования)

- Также отображается информация:
  - количество приглашённых пользователей
  - реферальный процент
  - реферальная ставка
  - общая заработанная сумма

---

## 🛠 Сценарий кнопки «Поддержка»

- Пользователь получает сообщение с:
  - контактами службы поддержки
  - часами работы
